# Images Directory

This directory should contain all the images you provided for the food truck website.

## Image Files to Add

Please add the following image files to this directory:

1. `topukki.jpeg` - The image of Tteokbokki (Korean spicy rice cakes)
2. `tiramisu.jpg` - The image of Tiramisu dessert
3. `veg_puffs.jpg` - The image of Vegetable puff pastries
4. `veg_scallion.jpeg` - The image of Vegetarian garlic scallion fried rice
5. `vegpulao.jpg` - The image of Vegetable pulao rice dish
6. `truck.png` - The food truck logo image

## How to Add Images

When deploying the website:

1. Create this directory structure: `/public/assets/images/`
2. Place all the image files you provided directly in this directory
3. Make sure the filenames match exactly as referenced in the code
4. The images will then be correctly displayed on your website

## Note on Image Paths

All image paths in the code are set to `/assets/images/filename.jpg` format. This ensures that when you add the actual image files to this directory, they will be correctly displayed on your website without any code changes needed.
